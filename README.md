# Trail Log

A personal hiking journal for CS4393. Log the trails you've completed with a photo, rating, and notes, and look back at the gallery.

**Team:** Elian García González, Martin Gonzalez

## Running it

Set up the environment (installs Node.js):

```sh
conda env create -f environment.yml
conda activate trail_log
```

Then install and run:

```sh
npm install
npm run dev
```

Open http://localhost:5173
